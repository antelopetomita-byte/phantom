Phantom かんたんマニュアル

はじめての人でも、これを読めば使えます。電話番号なし・登録なしで、消えるメッセージを送れるアプリです。

?Phantomってなに？

ひとことで言うと 「電話番号がいらない、消える暗号メッセージアプリ（レーダーの外へ）」 です。

  • 電話番号もメールも不要。 アプリを開くだけで自分専用のIDができます。
  • メッセージは自動で消えます。 読んだあと一定時間で消えるので、記録が残りません。
  • 中身は暗号化。 送った本人と相手だけが読めて、運営も第三者も中身を見られません。
  • アプリのインストール不要（ほぼ）。 スマホのブラウザで開いて「ホーム画面に追加」するだけ。
使う前に知っておくこと
Phantomは友達も一緒に使うことで成り立ちます。相手も同じようにPhantomを開いて、あなたと「つながる」必要があります（やり方は後で説明します）。

1はじめる（アカウントを作る）

所要時間30秒。名前も番号もいりません。

  1. スマホのブラウザ（iPhoneはSafari、AndroidはChrome）で Phantom のリンクを開く
  2. 最初の画面で ENTER を押す
  3. 新規作成 を選ぶ
  4. ニックネームは入れても入れなくてもOK（空ならIDが表示名になります）
  5. パスワードを決める（別の端末で同じIDを使うときに必要）
  6. これで完了。あなた専用の phantom_〇〇〇 というIDができます
大切：IDとパスワードは控えておく
このIDとパスワードは、スマホを変えたり入れ直したときに同じ自分に戻るための唯一の鍵です。忘れると同じアカウントに戻れません（新しい別人になります）。設定画面で確認できます。

2アプリとして使えるようにする

ホーム画面に置くと、普通のアプリのように使えて通知も受け取れます。

iPhone（Safari）

  1. Phantomを開いた状態で、画面下の共有ボタン（□に↑）を押す
  2. メニューから ホーム画面に追加 を選ぶ
  3. ホーム画面にできたアイコンから起動する

Android（Chrome）

  1. Phantomを開いた状態で、右上の⋮メニューを押す
  2. アプリをインストール（または「ホーム画面に追加」）を選ぶ
  3. できたアイコンから起動する
ヒント：LINEやSNSの中のブラウザで開くとうまくいきません。必ずSafariかChromeで開いてください。

3友達とつながる

Phantomは「招待リンク」か「QRコード」でつながります。電話番号での検索はありません（それが安全のポイント）。

あなたが招待する側のとき

  1. 設定（⚙️）を開く
  2. 招待リンク / QR を開く を押す
  3. 出てきたリンクを相手に送る（LINEやメールで）／またはQRコードを相手に見せる
  4. 相手がそれを開いて「つなぐ」と、お互いの一覧に表示されます

あなたが招待される側のとき

  1. 相手から届いた招待リンクを開く／またはQRコードを読み取る
  2. 画面の案内にそってつなぐ
  3. これで相手とつながり、メッセージが送れます
つながると：相手の名前が一覧に出て、タップすると会話が開きます。ヘッダーに 🔒 暗号化された会話 と出ていれば、安全に使える状態です。

4メッセージを送る

  1. 一覧から相手を選んで会話を開く
  2. 下の入力欄に文字を打つ（😊ボタンで絵文字も入れられます）
  3. 消えるまでの時間を選ぶ（入力欄の上のボタン。下の表を参照）
  4. 紙飛行機ボタン（▶）で送信

「消えるまでの時間」の選び方

残す消えません。ずっと残ります。
既読後24h相手が読んでから24時間後に消えます（おすすめの標準）。
既読後相手が読んですぐ消えます。
10秒〜10分送ってから決めた時間で消えます。

できること

  • 写真を送る：入力欄の左の画像ボタンから。写真も暗号化されます。
  • リアクション：メッセージを長押しすると 👍❤️😂 などを付けられます。
  • 取り消し／削除：自分のメッセージを長押しすると削除できます。
  • 通話：会話の上の電話マークで音声通話（お互いPhantom同士・無料）。

5通知を受け取る

  1. 設定（⚙️）を開く
  2. 通知（バナー＋未読バッジ）の横のボタンを オン（緑）にする
  3. 「通知を許可しますか？」と聞かれたら許可
  4. ちゃんと出るか不安なら 通知テスト ボタンで確認できます
iPhoneの注意：iPhoneのホーム画面アプリの通知は、Appleの仕様でときどき遅れたり届かないことがあります（アプリの不具合ではありません）。メッセージはアプリを開けば必ず読めます。Androidの方が通知は安定して届きます。

?よくある質問（FAQ）

お金はかかりますか？
無料です。メッセージも通話もデータ通信を使うだけで、通話料などはかかりません。
電話番号やメールは必要ですか？
不要です。アプリを開くだけでIDができます。だから身元がバレにくいのが特徴です。
相手がAndroid（またはiPhone）でも使えますか？
使えます。iPhoneでもAndroidでも、同じPhantomを開いて招待リンクでつながるだけです。相手のスマホの種類は関係ありません。
「🔒 復号できません」と出ました。
相手が一度アカウントを作り直したなどで、古い暗号の鍵が合わなくなったサインです。その相手との連絡先をお互いに削除して、招待リンクでつなぎ直すと直ります。なお、鍵が合わなくなった昔のメッセージは元に戻せません（安全のため）。
メッセージが相手に届かない／読めない。
多くの場合、上と同じ「つなぎ直し」で解決します。両方とも最新版にして（開くだけで自動更新されます）、連絡先を削除してから招待し直してください。
アプリを更新するには？
何もしなくてOKです。開くたびに自動で最新版になります。入れ直しは不要です。
スマホを変えたら、同じIDは使えますか？
使えます。新しい端末で最初の画面から ログイン を選び、控えておいたPhantom IDとパスワードを入れてください。「新規作成」を選ぶと別人になってしまうので注意。
本当に安全ですか？
メッセージ・グループ・通話はすべて暗号化され、運営も中身を見られません。ただし個人開発のため、Signalのような第三者の専門監査は受けていません。命に関わる極秘の連絡には、監査済みのSignalなどを併用してください。ふだんのプライベートな会話には十分な強さです。
スクリーンショットは防げますか？
どのアプリでも、相手が画面を撮影・保存することは技術的に完全には防げません。「消える」のはあくまでアプリ内での話、と考えてください。

✓こまったときの早見表

  • 読めない／届かない → 両方最新版に（自動）→ 連絡先を削除 → 招待し直す
  • 通知が来ない → 設定で通知をオン → 通知テストで確認（iPhoneは元々届きにくい）
  • 画面が古いまま → アプリを一度閉じて開き直す
  • 別のスマホで使いたい → ログインからID＋パスワードで
  • つながらない → SafariかChromeで開いているか確認（SNS内ブラウザは不可）
